Raspberry Pi
SPI0: MISO - GPIO4, CS - GPIO5, CLK - GPIO6
Daisy-chain of 2 74HC166 ICs
Read 16 bits
LSB bit 0 - DIGIT_2, bit is "1" - position active
bit 1 - DIGIT_3, bit is "1" -  position active
bit 2 - DIGIT_4, bit is "1" -  position active
bit 3 - BCD_4, bit is "1" -  bit is set
bit 4 - BCD_3, bit is "1" -  bit is set
bit 5 - BCD_2, bit is "1" -  bit is set
bit 6 - BCD_1, bit is "1" -  bit is set
bit 7 - DIGIT_5, bit is "1" -  position active
bit 8 - none
bit 9 - UNDER, bit is "1" - LED "underrange" is on
bit 10 - OVER, bit is "1" - LED "overrange" is on
bit 11 - DP_1, bit is "1", decimal point for DIGIT_1 is on
bit 12 - DP_2, bit is "1", decimal point for DIGIT_2 is on
bit 13 - DP_3, bit is "1", decimal point for DIGIT_3 is on
bit 14 - DP_4, bit is "1", decimal point for DIGIT_4 is on
MSB bit 15 - DIGIT_1, bit is "1" -  position active


SPI1: MISO - GPIO8, CS - GPIO9, CLK - GPIO10
Daisy-chain of 2 74HC166 ICs
Read 16 bits
LSB bit 0 - OHM, bit is "0" - LED "Ohm" is on
bit 1 - MOHM, bit is "0" - LED "MOhm" is on
bit 2 - V, bit is "0" - LED "V" is on
bit 3 - A, bit is "0" - LED "A" is on
bit 4 - KOHM, bit is "0" - LED "kOhm" is on
bit 5 - MV, bit is "0" - LED "mV" is on
bit 6 - MA, bit is "0" - LED "mA" is on
bit 7 - R, bit is "1" - LED "R" is on
bit 8 - none
bit 9 - POL, bit is "0", negative sign is on
bit 10 - HOLD, bit is "1" - LED "HOLD" is on
bit 11 - DIODE, bit is "1" - LED "Diode" is on
bit 12 - DC, bit is "1" - LED "DC" is on
bit 13 - AC, bit is "1" - LED "AC" is on
bit 14 - FREQ, bit is "1" - LED "Freq/KHz" is on
bit 15 - HFE, bit is "1" - LED "hFE" is on


External trigger (high to low) - GPIO11
Triggers when a BCD value for a certan DIGIT position is set

External trigger (none) - GPIO12
Reserved
